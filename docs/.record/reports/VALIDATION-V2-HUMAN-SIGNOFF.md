- 每个案例包含：
  - 20-bar 窗口的 K 线图
  - Pivot 点标注（蓝色 ▼ = High, 橙色 ▲ = Low）
  - Guard 水平线（紫色虚线）
  - Progress 水平线（青色虚线）
  - Event Bar 高亮（黄色竖线）

### 2. 人工审核流程
对每个案例执行：
1. **目视检查**: K 线图上的 Pivot 点是否在视觉上构成局部高/低点
2. **几何验证**: 中心 bar 的 high/low 是否严格高于/低于左右各 2 根
3. **延迟验证**: Pivot 确认是否在 extreme bar 后第 2 根发生
4. **Guard 合理性**: Guard 位置是否符合支撑/阻力逻辑
5. **状态一致性**: 状态转换是否符合 MALF v2.1 规格
