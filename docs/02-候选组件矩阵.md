# 02 — 候选组件矩阵

> 截至 2026-07-19 的候选登记；版本必须以机器实验输出和官方发布页为准。`selected` 只有主仓库批准后才能使用。

| 能力 | 候选 | 许可证 | 工厂状态 | RiskBench v0.1 建议 |
|---|---|---|---|---|
| 领域计算/TDX 解析 | Python 3.10+ 标准库 | PSF | candidate → 首批实测 | 主路径候选；保持领域核心无框架依赖 |
| 边界合同 | Pydantic v2 | MIT | candidate → 首批实测 | 只用于输入/快照/Viewer 合同 |
| 本地只读 HTTP | FastAPI | MIT | candidate → 首批实测 | Viewer 候选 |
| ASGI 服务器 | Uvicorn | BSD-3-Clause | candidate → 首批实测 | FastAPI 的运行时候选 |
| 单元/合同测试 | pytest | MIT | candidate → 首批实测 | TDD 主测试候选 |
| 浏览器验收 | Playwright Python | Apache-2.0 | candidate | 仅开发/验收依赖 |
| Python 环境/锁定 | uv | MIT OR Apache-2.0 | candidate | 与 venv/pip 对比后决定；非运行时 |
| 图表 | Apache ECharts | Apache-2.0 | candidate | 仅复杂交互确有需要时进入评审 |
| 金融图表 | TradingView Lightweight Charts | Apache-2.0（需按发行包核验） | candidate | 与 ECharts、原生 SVG 比较 |
| 图表零依赖 | 原生 HTML/CSS/SVG | 无第三方组件 | candidate | v0.1 默认基线 |
| 隧道 | frp / cloudflared / headscale | 各自许可证 | deferred | 不进入本轮本地纵切；另立部署门禁 |
| 反向代理 | Caddy | Apache-2.0 | deferred | 仅小主机/云阶段按专项安全设计评估 |

## 选择规则

1. 先用标准库验证领域核心；
2. 框架只解决边界问题；
3. 每个新增依赖必须有独立能力卡；
4. 复杂 UI 没有需求证据时，不引入 React/Vue/Vite；
5. 隧道和云服务不是 v0.1 技术栈的一部分。
