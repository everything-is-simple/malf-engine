## 🔧 关键实现细节

### resolution_distance_pct 公式修正
**之前（错误）**：
```python
resolution_distance_pct = abs(resolution_distance) / amplitude_init
```

**现在（正确，v2.1 Range §5）**：
```python
if resolution_type == "up":
    resolution_distance_pct = (confirmation_pivot_extreme_price - boundary_high_now) / boundary_high_now
elif resolution_type == "down":
    resolution_distance_pct = (boundary_low_now - confirmation_pivot_extreme_price) / boundary_low_now
```

### 为什么需要 confirmation_pivot_extreme_price？
- v2.1 Range §5 规定：`resolution_distance_pct` 基于 **确认 pivot 的极值价格**，而不是 resolution_distance
- 公式归一化到 **边界价格本身**（boundary_high_now 或 boundary_low_now），而不是 amplitude_init
